Comment les sources sont sélectionnées

1. Les publications de discussion

Le périmètre est r/manga. Je cherche les discussions du chapitre concerné, généralement intitulées [DISC], plutôt que les publications les mieux notées sur le manga. Les identifiants proviennent des recherches web et de recherches dans les archives autour des sorties ; je vérifie le chapitre, la date et, lorsqu’il est conservé, le lien vers Manga Plus.

Red Hood :18chapitres ; Ayashimon :25chapitres. Neru et Sakamoto Days :seulement les chapitres1,3,7,14,18, choisis comme points de comparaison. Ce n’est donc pas une étude de tous les posts Reddit consacrés à ces œuvres.

La recherche des doublons a été plus poussée pour Ayashimon. Les deux fils des chapitres1 et18 restent identifiables. Le titre du second fil du chapitre1 a disparu : son attribution repose sur les commentaires. L’exhaustivité de tous les fils parallèles n’est pas garantie, surtout pour les premières collectes.

2. Les commentaires servant à l’analyse

Échantillon reproductible : pour Red Hood,10commentaires à chacun des chapitres1,3,6,7,12,14,16,18 ; pour Sakamoto Days,10 aux chapitres1,7,14. Parmi les commentaires admissibles de premier niveau publiés à J+7, le tri est effectué par une clé calculée à partir de l’identifiant (SHA256), sans utiliser les votes ni choisir les opinions avant le tirage. Les critères d’exclusion et la clé sont conservés dans les scripts.

Citations ciblées : d’autres commentaires sont choisis parce qu’ils expliquent une attente, une critique, une évolution individuelle ou contredisent une interprétation. Les38annotations de l’étape4 appartiennent à cette catégorie. Les recherches de termes comme «Red Hood» ou «HxH» servent au repérage. Elles ne permettent pas de dire quel pourcentage du lectorat partage une opinion.

Les 80 commentaires Red Hood et les citations ciblées ne sont donc pas un seul échantillon. Ni les uns ni les autres ne représentent tous les lecteurs : ils décrivent les participants visibles dans les archives.
