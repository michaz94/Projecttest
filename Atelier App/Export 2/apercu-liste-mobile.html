3. L'extension <tabber> — ses onglets (Elric / Rockbell / …) découpent la section Families en sous-pages d'affichage. Dans chaque onglet : un simple {| tableau } wikicode qui empile les {{Char}}.

Comparaison des trois écoles de listes : catégorie = auto mais plate (aucun portrait, aucun ordre voulu) ; modèles-galeries (Hunterpedia) = manuel, images par groupe ; tabber + tableaux + modèle-case (FMA) = manuel, onglets par famille. Sur les deux wikis, la page-liste est taguée dans la catégorie « Characters » — les deux outils se complètent.
